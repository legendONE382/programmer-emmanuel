Infrastructure Monitoring / Analytics

VoltWatch AI

A voltage and power-reliability monitoring dashboard that simulates transformer telemetry, detects anomalies, and supports dispatch-style incident analysis.

Problem

Unstable power conditions are easier to respond to when voltage, temperature, and incident signals are visible in one dashboard.

What I built

A stateless Django command-center application with live telemetry simulation, anomaly detection, and incident triage through a backend proxy.

Key functionality

  • Real-time telemetry simulation
  • Voltage and temperature thresholds
  • Regional status grid and KPI analytics
  • Manual incident injection and dispatch guidance

Technical notes

Uses browser localStorage for history, Django for routing/API proxying, and Vercel-ready WSGI deployment.
